# Quick - Start

### Environments & Base URLs

* **Website:** `https://www.SOLkingdom.com`
* **Chain:** Solana mainnet for prod; devnet for testing
* **APIs/SDKs:** (provided in API Reference; endpoints may differ per env)

### Authentication

* **Wallet sign-in:** Phantom, Solflare , Backpack
* **Auth flow:** Wallet signature → short-lived session token (client) → signed requests
* **Staking eligibility:** ≥ 500 KC in wallet

### Quickstart

1. Connect wallet on homepage.
2. Swap SOL→KC.
3. Hold ≥ 500 KC to auto-stake at base 8% APR (boostable via points).
4. Open **Games** → choose **Degen Trader** or **SOLar Mission**.
5. Pay **12.5 KC** per session (10% burned), play, and earn points → boost APR tier.
