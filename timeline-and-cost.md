# Timeline and Cost

### **Project Deliverables**

1. Fully Functional SOLkingdom Platform
   * Website with games, staking dashboard, wallet integrations, Virtual BTC referral.
2. Two Blockchain Games
   * SOLar Mission crash game.
   * Degen Trader trading simulation.
3. KC Token Integration
   * Token contract, staking APR boosts, burn mechanics.
4. Leaderboards & Competitions
5. Virtual BTC Referral Program
6. Admin Tools & Analytics
7. Full Documentation & Deployment

| **Week 4**  | **Frontend Development – Phase 1**               | - Website home page, staking dashboard, wallet connection (Phantom, Solflare) - KC swap integration (SOL → KC)                                                                                                   | - Functional staking dashboard on devnet - Wallet integration working            |
