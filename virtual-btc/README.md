# Virtual BTC

### **Virtual BTC — What It Is**

Virtual BTC is not real Bitcoin, but an _in-game virtual currency unit_ used exclusively inside the SOLkingdom ecosystem for referral tracking and rewards.

* It’s a marketing and engagement mechanic, not a blockchain asset.
* It functions like a points system denominated in “BTC” to make it feel exciting/familiar for crypto users.
* You earn it only via referrals and certain promotional actions — you cannot buy it directly.
* It has no monetary value outside the platform but can be converted into KC (Kingdom Coin) at predefined rates when claiming referral rewards.

### **Core Purpose**

* **Gamify referrals**: Instead of boring referral codes and plain bonuses, you’re building a “Virtual BTC wallet” by inviting friends.
* **Social sharing incentive**: The more you share and get signups, the bigger your Virtual BTC balance, which later converts to KC you can actually stake or use in games.
* **Trackable growth**: Users can see exactly how much Virtual BTC their network has generated, which builds FOMO and competitiveness.
